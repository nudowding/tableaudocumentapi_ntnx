* instructions for building package

** install bazelisk

** make code changes eg. add a feature or fix a bug

** When ready to make a new package

*** update version
    Find this rule in =//BUILD.bazel=
    #+begin_src bazel -n 
      py_wheel(
	  name = "wheel",
	  distribution = "tableaudocumentapi_ntnx",
	  homepage = "https://github.com/nudowding/tableaudocumentapi_ntnx"
	  requires = [
	      "lxml",
	  ],
	  version = "0.11.2",
	  deps = ["//tableaudocumentapi"],
      )      
    #+end_src
    Update the version to a higher number. This is needed if using pip to upgrade.
*** build wheel
    #+begin_src sh :results drawer :wrap example :exports both
      bazel build //:wheel.dist
    #+end_src

    #+RESULTS:
    :results:
    #+begin_example

    #+begin_src sh :results drawer :wrap example :exports both

* instructions for publishing package

** Configure environment

#+begin_src bash -n
export TWINE_USERNAME=svc.daas.devops@nutanix.com
export TWINE_PASSWORD=xxxx
export TWINE_REPOSITORY_URL=https://artifactory.dyn.ntnxdpro.com/artifactory/local-nutanix-dspaas-pypi
export TWINE_CERT=$PWD/tools/artifactory.dyn.ntnxdpro.com.pem
#+end_src

You will need to get the password for =svc.daas.devops@nutanix.com= from Arun

** Publish the package

#+begin_src bash -n :results drawer :wrap example :exports both
bazel run wheel.publish
#+end_src
